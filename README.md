# RING BREAKER

프로레슬링 링에서 펼쳐지는 세로 화면용 벽돌깨기 로그라이트입니다. 공을 받아 선수와 챔피언을 격파하고, 웨이브 사이에 능력을 골라 한 번의 런을 완성하세요.

## 플레이

- 휴대폰에서는 경기장 안에서 손가락을 좌우로 움직여 패들을 조작합니다. PC에서는 마우스·트랙패드 또는 `←` `→` / `A` `D`를 사용합니다.
- **링에 오르기** 버튼 또는 `Space`로 시작합니다. 공이 경기장 아래로 떨어지기 전에 받아내세요. 체력을 잃으면 잠시 후 새 공이 자동으로 출발합니다.
- `Space` 또는 `Esc`로 일시정지·재개합니다. 공격으로 게이지를 채우면 피니셔 버튼 또는 `F`로 모든 상대를 공격합니다.
- 총 6개 웨이브를 돌파하면 우승합니다. 각 웨이브는 정해진 배치와 체력으로 구성되며, 마지막에는 챔피언이 등장합니다.
- 웨이브 사이에 제공되는 성장 카드 중 하나를 골라 현재 런을 강화합니다.
- 획득한 재화로 영구 훈련을 진행하면 다음 런에도 성장 효과가 이어집니다.

일반 버튼과 게임 조작부를 길게 눌러도 텍스트 선택, 이미지 드래그, 네이티브 메뉴가 열리지 않도록 처리했습니다. 페이지 스크롤과 확대는 사용할 수 있습니다.

## 로컬 실행

Node.js 22.12 이상과 npm이 필요합니다.

```sh
npm ci
npm run dev
```

개발 서버가 표시하는 주소를 브라우저에서 엽니다. 같은 네트워크의 모바일 기기에서는 개발 서버의 네트워크 주소로 접속할 수 있습니다.

```sh
npm test         # 게임 규칙 테스트 11개
npm run build   # TypeScript 검사 및 배포용 빌드
npm run preview # 빌드 결과 미리보기
```

배포용 정적 파일은 `dist/`에 생성됩니다. GitHub Actions에서도 의존성 설치, 테스트, 빌드를 실행합니다.

## 구성

- TypeScript · Vite
- Phaser 3 게임 렌더링과 입력
- 인라인 SVG 아이콘
- Vitest 게임 규칙 검증
- 프로레슬링 분위기의 프로젝트용 생성 이미지 어셋

이미지 생성 프롬프트와 파일 정보는 [docs/assets.md](docs/assets.md)에 기록되어 있습니다.

## 저장 데이터

영구 훈련과 진행 기록은 현재 브라우저의 `localStorage`에 저장됩니다. 서버 계정이나 기기 간 동기화는 사용하지 않습니다. 브라우저 데이터를 지우거나 다른 기기·브라우저를 사용하면 저장 기록이 이어지지 않습니다.
