# RING BREAKER — THE PIT UPDATE

[바로 플레이하기](https://rockyhong-a11y.github.io/ring-breaker/)

SLAY의 SD 레슬러로 즐기는 세로 모바일 볼 서바이벌 로그라이트입니다. 패들로 공을 받던 규칙을 바꾸어, 내려오는 상대 대열을 자동 연속 발사와 벽 반사로 돌파합니다. 경험치 보석을 모으면 전투 중 레벨업하여 액티브와 패시브를 성장시킵니다.

## 플레이

- 휴대폰에서는 링 안에서 좌우로 드래그합니다. PC에서는 마우스, `←` `→` 또는 `A` `D`로 노바를 움직입니다.
- **링에 뛰어들기** 또는 `Space`로 시작합니다. 공은 가까운 상대를 조준하여 자동으로 연속 발사됩니다. 적·벽에 맞아 튕기는 공은 여러 상대를 공격할 수 있습니다. 아래로 빠진 공은 체력을 깎지 않습니다.
- 적 대열이 링 아래에 도달하거나 상대 투사체에 맞으면 체력이 줄어듭니다. 이동으로 피하고, 경험치를 수집하세요.
- 경험치가 차면 경기가 멈추고 성장 카드 3개를 제시합니다. 하나를 선택하면 같은 웨이브의 전투가 이어집니다. 새 기술을 얻거나 기존 기술을 최대 5레벨까지 강화할 수 있습니다.
- **액티브는 최대 4개**까지 장착하며 자동 발동합니다. 불꽃 래리어트(화상), 빙결 드롭킥(둔화), 독 안개(중첩 중독), 번개 수플렉스(연쇄), 파워 밤(폭발), 태그 팀(분열), 레이저 촙(관통), 리턴 엘보(귀환)의 8종입니다.
- **패시브는 최대 6개**까지 장착합니다. 공격력, 발사 속도, 다중 발사, 벽 반사, 치명타, 경험치 수집, 처치 회복, 피해 감소의 8종입니다. 별도의 즉시 회복 선택지는 슬롯을 차지하지 않습니다.
- 총 **6개 고정 웨이브**를 돌파합니다. 3·5웨이브에는 아틀라스 중보스, 마지막에는 오닉스 챔피언이 등장합니다. 보스는 투사체를 발사하며 체력이 줄면 공격이 강화됩니다.
- 공격으로 피니셔를 충전합니다. 가득 차면 피니셔 버튼 또는 `F`로 광역 피해를 주고 상대 투사체를 제거합니다.
- `Space` / `Esc` 또는 일시정지 버튼으로 멈추고 재개합니다. 브라우저가 백그라운드로 이동하면 자동으로 일시정지합니다.

일반 적은 실제 SD 얼굴 이미지를, 중보스와 챔피언은 SD 전신 이미지를 사용합니다. 선수는 [SLAY](https://rockyhong-a11y.github.io/slay/)와 [SLAY Beach Volley](https://rockyhong-a11y.github.io/slay-beach-volley/)의 원본 SD 어셋을 재사용하며 MIT 저작권 표시를 포함합니다. [어셋 출처와 프레임 정보](docs/assets-v2.md)를 참고하세요.

일반 버튼과 게임 조작부를 길게 눌러도 텍스트 선택·이미지 드래그·네이티브 메뉴가 열리지 않습니다. 세로 스크롤, 핀치 확대, 키보드 접근은 유지합니다.

## 영구 성장과 저장

도전 보상으로 챔피언 토큰을 얻어 펀치 파워·빠른 손·아이언 하트를 훈련합니다. 기존 버전의 저장 데이터를 유지하며, 예전 패들 너비 훈련은 빠른 손(발사 속도와 보석 획득 범위)으로 적용합니다.

저장은 현재 브라우저의 `localStorage`에 보관됩니다. 토큰·영구 훈련·최고 기록은 유지되며, 진행 중인 전투는 새로고침 시 새 도전으로 돌아갑니다. 다른 브라우저나 기기와는 동기화하지 않습니다.

## 실행과 검증

Node.js 22.12 이상과 npm이 필요합니다.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
npm run verify:pages -- http://localhost:4173/ring-breaker/
```

개발 서버의 네트워크 주소로 같은 네트워크의 모바일 기기에서 테스트할 수 있습니다. `?debug=true`에서만 웨이브 이동·경험치 지급·능력 테스트 도구가 노출됩니다. 일반 URL에서는 노출되지 않습니다.

게임 규칙은 렌더러와 독립적인 고정 시간 간격 시뮬레이션이며, Phaser 3가 그래픽과 브라우저 입력을 연결합니다. 성장 정의는 `src/game/upgrades.ts`에서 모델·레벨업 선택지·도감·HUD가 공유합니다.

## GitHub Pages

Pages의 Source는 **GitHub Actions**를 사용합니다. `main`에 푸시하면 `.github/workflows/pages.yml`이 테스트와 빌드를 수행하고 `/ring-breaker/` 경로의 게임·SD 어셋을 검사한 뒤 `dist/`를 배포합니다.

배포 후 `npm run verify:pages`로 실제 사이트의 JavaScript MIME 타입과 하위 경로·이미지·설치 경로를 검사합니다. 저장소 루트를 브랜치 방식으로 배포하면 빌드 전 TypeScript가 제공되므로 사용하지 않습니다.
