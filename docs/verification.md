# The Pit Update 검증 기록

Node.js 24와 로컬 Chromium에서 검증했습니다. 실제 iOS Safari 기기 검증은 포함하지 않습니다.

## 게임 규칙과 자연 진행

`npm test`의 Vitest 테스트 19개가 통과했습니다. 고정 시간 간격 시뮬레이션, 자동 연속 발사, 실제 상대·벽 충돌과 도탄, 적 대열 전진, 경험치 획득과 전투 중 레벨업, 연속 레벨업의 남은 경험치 보존, 슬롯·레벨 상한, 각 속성의 실제 효과, 피니셔, 보스와 패배·재시작을 검사합니다.

디버그 웨이브 종료를 사용하지 않는 자연 진행 테스트도 포함합니다. 레벨업에서 유효한 성장을 고르면서 좌우 이동하는 플레이가 6개 웨이브를 모두 지나 승리하는지, 움직이지 않는 플레이가 마지막 보스에서 패배하는지 검사합니다. 첫 레벨업은 시뮬레이션 기준 약 7.5초입니다. 10개 시드의 별도 난이도 확인에서는 이동 플레이 9개가 승리하고 정지 플레이 10개는 모두 패배했습니다. 이 결과는 사람의 플레이 난이도나 승률 추정값이 아닙니다.

탄환 150개, 보스 투사체 70개, 경험치 100개, 모델 효과 60개, 이벤트 128개의 상한도 검사합니다. 명시적 시드는 재현 가능하며, 실제 브라우저에서 새 도전을 시작할 때에는 새로운 무작위 시드를 사용합니다.

## 브라우저 플레이 흐름

390×844 터치 컨텍스트에서 다음을 확인했습니다.

- 실제 자동 발사와 충돌로 약 7.5초에 8명을 처치하고 2레벨에 도달했습니다.
- 레벨업 시 세 가지 유효한 카드가 나타나며, Space로 선택해 같은 웨이브를 이어 갑니다.
- 액티브 8종·패시브 8종 도감 전환, 능력 상세 화면과 모달 일시정지·재개가 동작합니다.
- 경험치가 여러 레벨 분량 남으면 성장 선택창을 연속해서 표시합니다.
- 화염·빙결·연쇄 번개·폭발 액티브를 함께 장착했을 때 서로 다른 투사체를 자동 발사합니다.
- 3웨이브 중보스와 6웨이브 챔피언, 피니셔, 승리와 토큰 지급, 영구 성장 구매와 새로고침 후 저장 유지가 동작합니다. 전체 후반 흐름의 브라우저 검사는 `?debug=true` 도구로 가속했고, 모델의 자연 진행 검증은 별도입니다.
- 일반 URL에는 테스트 컨트롤러가 노출되지 않습니다.

기존 버전의 저장 데이터를 넣고 토큰·최고 기록·영구 훈련이 유지되는지도 확인했습니다. 브라우저 JavaScript 오류와 로컬 에셋 4xx 응답은 없었습니다.

## SD 어셋

원본 참고 게임의 SD 노바 전신, 얼굴 WEBP 4종, 중보스 아틀라스·최종 보스 오닉스 전신을 실제 런타임에서 로드합니다. [어셋 출처](assets-v2.md)에 소스 커밋·해시·MIT 표시·프레임 경계를 기록했습니다.

## 모바일 제스처

도움말 버튼·일시정지 버튼·게임 캔버스에 실제 850ms 길게 누르기를 수행한 후 텍스트 선택이 없었습니다. 일반 버튼과 게임 조작부의 `contextmenu`, `selectstart`, `dragstart` 취소, textarea의 선택 이벤트 유지도 확인했습니다.

가로 드래그로 노바가 이동했습니다. 캔버스에서 실제 세로 스와이프 후 페이지가 165px 스크롤됐고, 핀치 제스처 후 `visualViewport.scale`이 1에서 약 1.3으로 변했습니다. 360·390·768·1440px 화면에서 가로 넘침이 없었습니다.

## 빌드와 Pages

TypeScript 검사와 프로덕션 빌드를 실행합니다. `npm run verify:pages`는 실제 배포 HTML이 빌드된 JavaScript를 참조하는지, 올바른 MIME 타입인지, `/ring-breaker/` 아래에서 SD 이미지·CSS·앱 아이콘·설치 경로를 사용할 수 있는지 확인합니다. Pages 배포 워크플로도 업로드 전에 같은 경로 검사를 수행합니다.
