# 360° Pit Update 검증 기록

2026-10-16, Node.js 24와 로컬 Chromium에서 검증했다. 실제 iOS Safari 기기 검증은 포함하지 않는다.

## 규칙과 밸런스

`npm test`의 모델 테스트 **28개**와 TypeScript 검사·프로덕션 빌드가 통과했다. 상하좌우 이동, 대각선 정규화, 네 방향 경계·조준·접촉·벽 반사, 좌우 기습 경고, 보스 경고와 안전한 등장 위치, 여섯 대형, 세 난이도와 세 단계, 기존 액티브·패시브 효과 및 슬롯·레벨 상한을 검증한다.

동일한 5개 시드를 사용한 이전 모델과의 비교에서는 고정 이동·성장 정책의 클리어가 기존 5/5에서 도전자 2/5, 하드 1/5, 나이트메어 0/5로 감소했다. 새 모델의 정지 정책은 모두 0/5였다. 이는 작은 자동화 회귀 표본이며 사람의 승률이 아니다. 정책·시드별 결과와 한계는 [게임플레이 문서](pit-gameplay.md)에 기록했다.

## 브라우저 흐름

- 360×844, 390×844, 768×1024, 1440×900, 390×650에서 캔버스가 뷰포트 전체를 채우고 페이지 넘침이 없다. 링과 캐릭터 비율을 유지하며 넓은 화면에서는 HUD 영역을 확보한다.
- 실제 모바일 터치로 상·하·좌·우와 대각선 이동, 포인터 캡처를 검증했다. PC 방향키와 WASD도 두 축으로 이동한다.
- 난이도 선택과 새로고침 후 복구, 기존 토큰·최고 기록·영구 훈련 저장 승계를 확인했다.
- 기본 하드의 자연 진행에서 약 8.3초에 첫 레벨업했다. 성장 카드 3개, 키보드 선택, 여러 레벨 분량의 성장 연속 선택 후 전투 재개를 확인했다.
- 액티브 8종·패시브 8종 도감, 능력 상세, 모달의 일시정지·재개, 서로 다른 자동 발사 액티브를 확인했다.
- 중보스·보스 전신, 피니셔, 승리와 토큰 지급, 트레이닝 구매 및 저장을 확인했다. 후반 브라우저 검사는 `?debug=true`로 가속하며, 자연 진행 검증은 별도로 수행한다. 일반 URL에는 테스트 컨트롤러가 노출되지 않는다.

## 모바일 제스처

일반 도움말 버튼, 일시정지 버튼, 게임 캔버스에 850ms 실제 길게 누르기를 수행한 후 텍스트 선택이 없었다. 비편집 UI의 `contextmenu`, `selectstart`, `dragstart` 취소와 포인터 캡처를 확인했다. input·textarea·select·contenteditable의 이벤트는 취소하지 않는다.

게임의 세로 드래그는 이동으로 사용한다. 도감 모달에서는 실제 세로 스와이프로 네이티브 스크롤이 동작하며, 게임 캔버스의 `touch-action: pinch-zoom`으로 실제 핀치 확대를 유지한다.

## 그래픽과 배포

SLAY의 원본 SD 얼굴과 선수·중보스·최종 보스 전신 이미지를 유지한다. [어셋 출처](assets-v2.md)에 커밋·해시·MIT 표시·프레임 경계를 기록했다. 링의 직물·흠집·조명·로프와 적 블록의 금속 프레임은 런타임에서 재사용 가능한 텍스처로 그린다.

Higgsfield 생성 요청은 연결 계정의 권한 제한으로 제출 전에 거절됐다. 현재 배경과 블록에 Higgsfield 생성 이미지는 사용되지 않는다. [준비 프롬프트와 결과](higgsfield-assets.md)를 기록했다.

`npm run verify:pages -- http://localhost:4173/ring-breaker/`로 프로덕션 미리보기의 빌드 JavaScript·MIME 타입·하위 경로·SD 이미지·CSS·아이콘·설치 경로를 확인했다. GitHub Actions도 같은 검사를 수행한 뒤 빌드 결과를 배포한다.
