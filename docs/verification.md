# 검증 기록

2026-10-16, Node.js 24와 로컬 Chromium에서 검증했습니다.

## 게임 규칙

`npm test`의 Vitest 테스트 11개가 통과했습니다. 고정 시간 간격 시뮬레이션, 벽·패들·상대 충돌, 패들 각도, 입력 범위, 체력 손실과 게임 오버, 웨이브 전환과 보상 선택, 업그레이드 중첩·초기화, 피니셔 소모, 챔피언과 승리를 검증합니다.

`npm run build`의 TypeScript 검사와 Vite 프로덕션 빌드가 통과했습니다. Phaser가 포함된 게임 번들은 약 348KB gzip입니다.

## 모바일 브라우저

Playwright로 독립 Chromium 컨텍스트를 생성하고, 390×844 터치 화면에서 실제 CDP 터치 이벤트를 보냈습니다.

- 도움말 버튼, 일시정지 버튼, 게임 캔버스를 850ms 동안 길게 누른 후에도 텍스트 선택이 발생하지 않았습니다.
- 캔버스·일반 버튼·모바일 내비게이션의 `contextmenu`, `selectstart`, `dragstart` 취소를 확인했습니다. 임시 textarea의 선택 이벤트는 취소되지 않았습니다.
- 가로 드래그로 패들이 210에서 347로 움직였습니다.
- 게임 캔버스에서 세로 스와이프 후 페이지가 165px 스크롤됐습니다.
- 실제 핀치 제스처 후 `visualViewport.scale`이 1에서 1.35로 커졌습니다.
- 360px, 390px, 768px, 1440px 화면에서 가로 넘침이 없었습니다.

## 플레이 흐름과 저장

실제 공 충돌과 점수 증가를 확인했습니다. 일반 조작으로 일시정지·재개, 도감 열기·닫기, 피니셔 발동을 검증했습니다. 네이티브 대화상자 안의 기술 선택과 트레이닝 구매는 Space 키로도 작동했습니다.

전체 경기 흐름은 `?debug=true`에 한해서 노출되는 테스트 도구로 웨이브 종료를 가속했습니다. 6개 웨이브, 40HP 챔피언, 승리 화면, 1회 보상 지급, 영구 능력 구매, 다음 도전의 능력 반영, 3회 체력 손실에 따른 게임 오버, 새로고침 후 저장 유지까지 검증했습니다. 일반 URL에서는 테스트 도구가 노출되지 않습니다.

실행 중 브라우저 JavaScript 오류는 0개였습니다. 실제 iOS Safari 기기 검증은 포함하지 않았습니다.
